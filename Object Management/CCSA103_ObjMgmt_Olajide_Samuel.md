# Part 3: Short-Answer Questions

1. What is a recommended best practice when dealing with default objects in SmartConsole, rather than editing them directly? 
> When dealing with default objects, it is always recommended to clone the object and make any required changes to the cloned object instead of editing the object directly.

3. What is the Object Explorer, and what is one unique capability it has that the standard New menu does not?
> The Object Explorer can be used to manage all types of objects. It has a unique capability because it can be used to view all existing objects, while the standard New menu only allows limited management of objects.

4. According to best practices, why should you use Group Objects instead of adding individual objects directly to security rules?
> Using a Group Object allows the management of security rules to be simplified by automatically applying membership changes across associated rules while keeping the rulebase organised and reducing the number of individual rules.
